# MedLife — Respect Infinit (subscriber pricing)

Part of [Whoop Biomarkers — Romanian Lab Mapping](README.md). Same tests, same
Blocks as [SHOPPING-LIST-MEDLIFE.md](SHOPPING-LIST-MEDLIFE.md) — this file
shows what changes if you hold a Respect Infinit subscription (539 RON/month,
12-month validity).

Respect Infinit gives two separate things. An **annual set** of 11 tests is
included with no referral, capped 1×/year each. A much larger **discount
annex** — about 19 test categories at 100% off — needs "cu recomandarea
medicului MedLife" (a MedLife doctor's referral) and is capped 4×/year per
test. Annual-set lines below show the standard price struck through, then
**0 (free 1×/year)** — a guaranteed benefit, no doctor's discretion involved.
Annex lines show the standard price struck through, then **0 (estimated,
referral, 4×/year cap)** — not guaranteed the way the annual set is, since
enforcement of the referral is a GP's individual call. A plain price with no
strikethrough means that test is on neither list. Several tests sit on both
lists at once; those are marked with the annual-set's simpler, guaranteed
caveat, since it's the better route for the first order each year — the
annex can still supply additional free draws of the same test later in the
year, up to its own 4×/year cap.
