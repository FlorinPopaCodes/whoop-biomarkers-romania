# Whoop Biomarkers — Romanian Lab Mapping

Whoop Advanced Labs is only available in the US. From Romania you can still
upload your own lab results, which is free on any membership, and Whoop will
show any biomarker it supports. This repo covers all 127 of them: which test
measures each one at Synevo, Regina Maria and MedLife, and what it costs.

Catalogues: [Synevo](https://www.synevo.ro/shop/) ·
[Regina Maria](https://www.reginamaria.ro/laboratoare-inteligente/gama-de-analize) ·
[MedLife](https://www.medlife.ro/gama-analize)

## Which provider

| Provider | Core | Subscriber (est.) |
|---|---:|---:|
| Synevo | **1,856 RON** · 57/57 | — |
| Regina Maria | 2,220 RON · 57/57 | ~915 RON |
| MedLife | 1,914 RON · 57/57 | ~866 RON |

**Synevo is the cheapest**: 58 RON less than MedLife and 364 RON less than
Regina Maria.

All three sell all 57 Core biomarkers, so the totals compare the same set of
tests. The subscriber figures are estimates: most of the discount only applies
if one of that provider's own doctors recommends the test. Each shopping list
shows which lines are guaranteed and which aren't.

Beyond Core, Synevo and MedLife each sell 34 of the 43 Extended biomarkers you
can buy. Regina Maria sells 29, and 4 more are unresolved.
[BIOMARKERS.md](BIOMARKERS.md) gives each provider's name for each biomarker and
shows who sells what.

## What to order

Each provider has a shopping list, split into blocks with a subtotal and
biomarker count for each:
[Synevo](SHOPPING-LIST-SYNEVO.md) ·
[Regina Maria](SHOPPING-LIST-REGINA-MARIA.md) ·
[MedLife](SHOPPING-LIST-MEDLIFE.md)

If you have a Regina Maria Comfort Premium or MedLife Respect Infinit
subscription, the list has a second price column for it.

Some tests are also free once a year on a referral from your family doctor. You
qualify if you're insured, have no symptoms, aren't registered with a chronic
disease, and have at least one modifiable risk factor. That covers about 149–182
RON of each list, or 205–250 RON for women from 40. The lists mark those lines
with `§` and give the age and sex rules.
