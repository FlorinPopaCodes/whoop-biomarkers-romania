# Regina Maria — Comfort Premium (subscriber pricing)

Part of [Whoop Biomarkers — Romanian Lab Mapping](README.md). Same tests, same
Blocks as [SHOPPING-LIST-REGINA-MARIA.md](SHOPPING-LIST-REGINA-MARIA.md) — this
file shows what changes if you hold a Comfort Premium subscription.

Comfort Premium discounts ~300 lab tests 100%, but only "la recomandarea
medicului RM" — with a referral from an RM doctor, which is a GP's call and
varies. Discounted lines below show the standard price struck through, then
the subscriber price marked **(estimated)**; a plain price with no strikethrough
means that test isn't on the discount annex, subscription or not.
